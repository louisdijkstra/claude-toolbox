The circle ramp

Five states, so each circle covers a 25-point band. This is the whole vocabulary — everything below is built from it.

○ ◔ ◑ ◕ ●
0% 25% 50% 75% 100%

The cost of five states: 45% and 54% both round to ◑. A single circle tells you which quarter you are in, not where in it. Variant C keeps circles and gets the resolution back; the rest accept the rounding and print the number beside it.

Which glyph marks a worktree

A worktree is a second checkout of one repository — a linked copy, not a branch. The glyph should say copy or derived, not fork.

GlyphNameReads as
⧉stacked squaresA linked copy of the same thing. Closest to what a worktree is, and distinct from every branch glyph.
↳corner arrowDerived from the thing on its left. Reads naturally as my-app ↳ feature-x, and needs no legend.
⎇alternateThe standard branch symbol. Precise for people who know it, invisible to everyone else, and it says branch when we mean worktree.
⋔pitchforkA split into parallel paths. Suggestive, but easily mistaken for a merge or a fork.
»guillemetPlain descent. No git meaning at all, which makes it quiet — and ambiguous with a path separator.
◫divided squareOne container, two panes. Same idea as the stacked squares but flatter, and it sits closer to the circle meters.

Each variant below uses a different one, so you can judge them in place rather than in a table. My pick is ↳ for reading without a legend, ⧉ if you want the sharper distinction from a branch.

Cost: the branch is only identifiable by colour, so it disappears in a monochrome terminal or a piped log.

On the circles. ○ ◔ ◑ ◕ ● are East Asian Ambiguous width: most terminals draw them one column wide, but a terminal configured with a CJK font may draw them two, which shifts everything after them. If that happens here, the same shapes exist in the block ramp ░ ▒ ▓ █, which is unambiguous — the layout survives the swap.

On the tree. 🌳 was doing a job no other glyph on the line does: it is instantly readable with no legend. Anything replacing it trades that recognition for width — an emoji costs two columns and aligns unreliably, a geometric glyph costs one and needs learning once.

Every variant keeps the same fields and both reset countdowns, in all three states.
